# Loja Virtual de Móveis

## 1. Nome do Sistema
Loja Virtual de Móveis (E-commerce do setor moveleiro).

## 2. Objetivo do Sistema
Desenvolver uma plataforma de e-commerce voltada para o setor moveleiro, permitindo o cadastro de produtos com dimensões detalhadas, carrinho de compras, cálculo de frete, gestão de estoque e checkout seguro.

## 3. Principais Funcionalidades
- Autenticação e cadastro de clientes.
- Gestão de catálogo de móveis com dimensões.
- Busca e filtros avançados.
- Carrinho de compras dinâmico.
- Processamento de pagamentos (PIX, cartão, boleto).
- Cálculo automático de frete.
- Rastreamento de pedidos.
